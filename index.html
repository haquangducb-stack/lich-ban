Hướng Dẫn Đưa Lên GitHub Pages

Để lưu trữ và chia sẻ web app Lịch Bản miễn phí trên GitHub Pages, bạn thực hiện các bước cực kỳ đơn giản sau:

  1. Đăng nhập vào tài khoản GitHub của bạn.
  2. Tạo một Repository (kho lưu trữ) mới, đặt tên ví dụ: lich-ban. Chọn chế độ Public.
  3. Tạo một file mới trong repository đặt tên chính xác là: index.html.
  4. Copy toàn bộ mã nguồn của file HTML này dán vào file index.html trên GitHub rồi ấn Commit changes.
  5. Vào mục Settings của repository > Chọn tab Pages ở menu bên trái.
  6. Ở phần Build and deployment > Branch, chọn nhánh main (hoặc master) và thư mục / (root), sau đó ấn Save.
  7. Chờ khoảng 1-2 phút, GitHub sẽ cung cấp cho bạn một đường link trực tuyến công khai để truy cập ứng dụng từ bất kỳ thiết bị nào!
